    SLAAC oder DHCPv6?

    IPv6-Geräte können ihre Adresse selbst bilden (SLAAC). Mit DHCPv6 vergibt stattdessen ein Server die Adressen. Das ist nützlich, wenn man genau wissen will, welches Gerät welche Adresse hat. Welches Verfahren gilt, sagt das Router Advertisement: Ist das M-Flag (managed) gesetzt, fragen die Geräte per DHCPv6.

    Ablauf

    SchrittInhalt
    SolicitClient sucht einen Server (Multicast an alle DHCP-Server)
    AdvertiseServer bietet eine Adresse an
    RequestClient wählt das Angebot
    ReplyServer bestätigt

    Der Client weist sich mit einer DUID aus (in leyoNET aus der MAC abgeleitet). Das Gateway bekommt er weiterhin aus dem Router Advertisement, nicht per DHCPv6.

    DNS-Server für IPv6

    Den DNS-Server erfahren IPv6-Geräte entweder per DHCPv6 oder direkt im Router Advertisement (RDNSS-Option). In leyoNET trägt man ihn beim Router-Anschluss ein.
