    Running exams

    Exam file and key, variants per seat, exam mode, Safe Exam Browser, web version with seat codes and automatic evaluation.

    On this page
    1. Principle
    2. Creating an exam
    3. During the exam
    4. In the web version
    5. How to do it in leyoNET
    6. Read on

    Principle

    An exam consists of two files: the exam file for the learners (task, starting network, points per part, without check blocks and solutions) and the key for you (all check blocks, solutions, code to end the exam). Evaluation uses the key.

    Creating an exam

    • Generator: Tools → Create exam generates a company network with three sites, 75 points, grade = 5 × points / 75 + 1. A separate variant per seat is possible.
    • Any task as an exam: Tools → Save as exam, with an empty starting network, devices only, the current network or as troubleshooting with random faults per seat.
    • With an AI: Tools → Tasks with AI creates instructions with rules, the schema of all checks and the open task as an example. You paste the AI's reply back; leyoNET checks it strictly and opens it in the task editor. Solve it once yourself, then save it as an exam. leyoNET sends nothing to an AI; do not give it personal data.
    • Fairer marking: partial points, follow-on errors (gateway “a router in its own network”), questions directly in leyoNET, “manual” blocks.

    During the exam

    Opening the exam file starts the exam mode: catalog, demos, task editor and opening other files are locked, a bar shows title, seat and time. It survives a reload and only ends with your code. For locked-down computers leyoNET generates a configuration for the Safe Exam Browser.

    In the web version

    Upload exam file and key in the admin console, print seat cards with seat codes, start. Work is saved every 20 seconds; when time is up it is handed in automatically. The exam cockpit shows per seat whether it is connected, allows extra time (+5′, +15′) and live “watching”. At the end leyoNET evaluates all seats, with manual correction and a report.

    Procedure, limits and what leyoNET can do against copying: exams (in German).

    How to do it in leyoNET

    The same text as in the app’s help (F1 key).

    Exams in the web version

    In the web version, exams run through the server without sending files back and forth.

    Teacher (Tools → Admin console → Exams): - upload the exam file and key, set seats and minutes - print seat cards and hand them out: each seat has its own seat code. Who sits where is only in your seating list or on the card – the server knows no names - start, give extra time per seat (+5′, +15′, also later), end for everyone - evaluate automatically: all submissions corrected with the key; a name list (“07 Anna Example”) can be pasted into the review window and stays there only - download submissions: one file with all submissions and the key, which “Review submissions” can evaluate later

    Learners: File → Join exam … → seat code. Before the start they wait. Work is saved every 20 seconds; when time is up, the last saved state counts as submitted. The server deletes everything after 60 days. Safe Exam Browser: When creating, choose «Safe Exam Browser only». The cockpit creates a SEB file with start, admin and quit password and a random exam key that is valid until the exam ends. Without SEB the server accepts neither joining nor saving.

    Tasks with AI

    Under Tools → Tasks with AI, leyoNET creates instructions (a prompt) for an AI of your choice: rules (private addresses only per RFC 1918/5737, domains ending in .example), the complete schema with all checks and the open task with its start network as an example. You can add what you want, e.g. “exam for M117, two VLANs with DHCP, 30 points”.

    • Copy instructions or Save as file and paste them into the AI.
    • Paste the AI's reply (a JSON object in the format “leyonet-ki-aufgabe”) here or open it as a file and click Import.
    • leyoNET checks everything strictly: device types, names, addresses, cables and every check. On an error nothing is imported and the message names the place.
    • The task is then in the editor. Solve it once yourself and save it as a task or with Tasks “Save as exam”.

    leyoNET does not connect to any AI and sends nothing. Do not give the AI personal data (names of learners).
