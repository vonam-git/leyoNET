    What for

    People remember www.schule.example, devices need 192.168.0.3. The Domain Name System translates names into addresses. Every computer has a DNS server configured for this (static or via DHCP) and asks it before opening a connection.

    Records

    TypemapsExample
    Aname → IPv4 addressweb.schule.example A 192.168.0.3
    AAAAname → IPv6 addressweb AAAA 2001:db8::3
    CNAMEalias → another namewww CNAME web
    MXdomain → mail server (with preference)schule.example MX 10 mail
    NSdomain → responsible name server
    PTRaddress → name (reverse lookup)
    TXTfree text

    Every record has a TTL: a client may keep the answer in its cache for that long.

    How a query works

    1. The browser wants www.schule.example and asks the DNS server (UDP, port 53).
    2. The server finds www as a CNAME for web and the A record for it.
    3. It answers authoritatively with the chain; the client remembers the result.
    4. If the server does not know the zone, it forwards to another DNS server (e.g. the provider’s) and answers “non-authoritative”.

    Example names end in .example, a domain that according to RFC 2606 is never assigned.

    In leyoNET

    A server becomes a DNS server under Advanced → Services and gets a zone.

    C:\> nslookup www.schule.example
C:\> nslookup -type=MX schule.example
C:\> nslookup 192.168.0.3
C:\> ipconfig /displaydns
C:\> ipconfig /flushdns

    DNS

    DNS translates names into addresses and back. The client asks its DNS server via UDP port 53 and caches the answer for its TTL (ipconfig /displaydns, ipconfig /flushdns).

    • A and AAAA: name → IPv4 or IPv6 address
    • CNAME: alias for another name (the server follows the chain)
    • MX: mail server of a domain; the smallest preference wins
    • TXT: text, e.g. an SPF rule
    • NS: name server of the domain
    • PTR: address → name (reverse lookup under in-addr.arpa or ip6.arpa)

    The server answers names in its own zone authoritatively. With forwarding it asks another server (e.g. the provider's) for all other names and answers “non-authoritative”. Test with nslookup -type=MX school.example, nslookup 192.168.0.3 (PTR) or nslookup name server (ask a specific server).
