    Module 117: IT and network infrastructure

    The series for the Swiss ICT module 117 “IT and network infrastructure for a small company”: from the first switch via routers and transit networks to DHCP, DNS and a web server.

    Standard
    RFC 791, RFC 1918, RFC 2131 …

    What it is about

    In module 117 learners plan and build the IT and network infrastructure of a small company. With leyoNET this works without a tangle of cables: build networks, assign addresses, connect routers and set up services such as DHCP, DNS and a web server. Every exercise checks itself, the worksheet records the reasoning.

    The series fits the first year of vocational training (feature profiles 1 and 2). The exercises build on each other; once a level is mastered, take the next one.

    Theory in this order

    1. OSI model and encapsulation: layers and encapsulation, so it is clear who reads what.
    2. Number systems and addresses and Subnetting and VLSM: network part, host part, mask.
    3. Switch and Router: who connects within a network, who between networks?
    4. How routing works and Static routing: default gateway and transit network.
    5. DHCP, DNS and HTTP: the services in the company network.
    6. ICMP, ping and traceroute: troubleshooting with ping and traceroute.

    Teaching tips

    • Start with the “Starter” profile; switch to “Basics” for the services.
    • The demos “ARP and ping in the LAN” and “Default gateway” are good to present before the first exercise.
    • The last exercise (Holzer AG) works as exam preparation; for the exam itself there is the exam mode with variants per seat (Running exams).

    Standards

    • RFC 791 – Internet Protocol
    • RFC 1918 – Address Allocation for Private Internets
    • RFC 2131 – Dynamic Host Configuration Protocol
    • RFC 1035 – Domain Names – Implementation and Specification
    • RFC 826 – An Ethernet Address Resolution Protocol

    Read on

    • OSI model and encapsulation Seven layers that describe every network connection, and why a packet is built like a Russian doll.
    • Subnetting and VLSM Split a network into smaller ones, read masks and prefixes, compute host range and broadcast – evenly or as needed.
    • How routing works Default gateway, routing table, longest prefix and administrative distance – and when to route statically, automatically or dynamically.
    • DHCP Handing out addresses automatically: discover, offer, request, ack, lease time, fixed assignments and DHCP relay across routers.
    • DNS Translating names into addresses: zones, records (A, AAAA, CNAME, MX, PTR …), forwarding, cache and nslookup.
    • Router Connects networks: routing table, default gateway, NAT, DHCP relay, dynamic routing, VPN and command line.
    • Switch Connects devices in the same network, learns MAC addresses, separates networks with VLANs and prevents loops with spanning tree.
