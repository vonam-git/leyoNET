    Exercises and worksheets in class

    The exercise catalog with over 70 self-checking exercises, the worksheets that go with them and how to evaluate a whole class’s submissions.

    On this page

    2. Worksheets
    3. Evaluating submissions

    How an exercise works

    Tools → Exercise catalog opens all exercises, by stars (★ to ★★★★★), topics and module series (M117, M129, M145). An exercise loads a starting network and shows the learning goals on the left, e.g. “PC 1 reaches the web server”. Check runs the simulation in the background and ticks off what is fulfilled, with a hint for every open goal. Solved exercises stay marked in the catalog.

    Every exercise switches on the features it needs. Each has a model solution in the code that is checked automatically at every release. So there cannot be an exercise that is impossible to solve in leyoNET.

    Worksheets

    Every exercise has a fillable worksheet (PDF, in German) with the questions that cannot be checked automatically: computing the network ID, observations in the packet list, reasoning. The worksheets are in the project under docs/arbeitsblaetter and in every release as a ZIP. Model solutions are available to teachers on request (address in the legal notice).

    Evaluating submissions

    Learners save their project (Ctrl+S) and hand in the file, e.g. via Teams or Moodle. Evaluate submissions … (on the left under “Task”) loads all files of a class at once, checks each against the learning goals and exports the result as CSV for Excel. The web version needs no files: you see the class’s sessions directly (Web version: sessions, classes and watching).

    How to do it in leyoNET

    The same text as in the app’s help (F1 key).

    Tasks

    The catalog (stars = difficulty) contains ready-made exercises; each checks its goals automatically. The tabs at the top (M117, M129, M145 …) show the exercises of one module with progress; each has a fillable worksheet (PDF). The search field and the topics (VLAN, DHCP, OSPF …) filter the list, “Only matching my profile” hides exercises that need other features. Teachers create their own under Tools → Create task from check blocks (ping, DHCP, route learned, questions, documentation, by hand …); «Suggest goals from this network» turns a finished solution into a task. Goals can have points and partial points; with «Grade» leyoNET computes the grade on the Swiss scale (5 × points / maximum + 1). When all goals are met, the catalog shows the exercise as ✓ done. Long assignments also open in a large window with paragraphs, lists and highlighted commands and addresses; ⤢ Show large opens it at any time, Esc closes it. You can keep working next to it.

    Exams: «Tools → Save as exam» or the generator «Tools → Create exam» produce an exam file without checks and solutions (also one variant per seat or a troubleshooting exam with random faults) and a key for the teacher. The exam file locks catalog, editor, generator and evaluation until the teacher ends the exam with their code. Evaluate submissions checks all files with the key; points can be corrected by hand, reports are available for review, strikingly similar submissions are flagged.
