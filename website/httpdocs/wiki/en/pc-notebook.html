    PC and notebook

    End devices with a desktop: command line, web browser, e-mail and network settings – static or via DHCP.

    Layer
    1 bis 7 (Endgerät)

    What for

    PCs and notebooks are the devices people work on. They send and receive but do not forward anything. The notebook can also join the network via Wi-Fi; a PC needs a cable.

    Settings

    SettingMeaning
    IP address and maskown address and size of the network
    Default gatewayrouter that receives everything not in the own network
    DNS serverwho translates names like www.schule.example into addresses
    DHCPeverything automatically from the DHCP server instead of fixed values
    IPv6automatic (SLAAC/DHCPv6) or static, depending on the project’s IP version

    The desktop

    In the simulation a double-click opens the device’s desktop:

    • Command line: ping, tracert, ipconfig /all, ipconfig /release and /renew, arp -a, nslookup, netstat, ssh.
    • Web browser: shows every step (DNS, TCP, HTTP) and the page.
    • E-mail: sending via SMTP, fetching via POP3 or IMAP.
    • Network: addresses and tables at a glance.
    C:\> ipconfig /all
C:\> ping 192.168.1.1
C:\> tracert www.schule.example

    How to do it in leyoNET

    The same text as in the app’s help (F1 key).

    PC

    End device with one Ethernet port. Needs an IP address, mask, gateway and DNS server (IP addresses). Its desktop has a command prompt (ping, tracert, ipconfig, nslookup), a browser and mail.

    Notebook

    End device with Ethernet and Wi-Fi. Gets its address statically or via DHCP. When on Wi-Fi it roams to the closer access point if moved during simulation (Roaming).
