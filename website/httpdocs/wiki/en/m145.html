    Module 145: Operating and extending a network

    The series for the Swiss ICT module 145: VLANs, trunks, router on a stick, layer 3 switch with ACL, DHCP with relay and network design with three-tier and collapsed core.

    Standard
    IEEE 802.1Q, IEEE 802.1D, IEEE 802.1AX …
    On this page
    1. What it is about
    2. Theory in this order
    3. The exercise series
    4. Teaching tips
    5. Standards
    6. Read on

    What it is about

    In module 145 an existing network is operated and extended. The focus is on VLANs: separating departments, trunks between floors, routing between VLANs with router on a stick or a layer 3 switch, DHCP via a relay and finally a clean network design with redundancy.

    The series starts with the “old-school network” with one router per network and ends with three-tier and collapsed core. The extra tasks practise troubleshooting, management VLAN and port channel.

    Theory in this order

    1. Ethernet and MAC addresses and Switch: how a switch learns and forwards.
    2. VLANs and trunks: access and trunk ports, the 802.1Q tag, native VLAN.
    3. Router and Layer 3 switch: routing between VLANs.
    4. Access control lists (ACL): restricting access between VLANs.
    5. DHCP: pools on the layer 3 switch and relay to a central server.
    6. Spanning tree (STP) and Port channel and LACP: redundant links without loops.
    7. Network design: core, distribution, access: core, distribution and access.

    Teaching tips

    • UE05 “Who receives the broadcast?” works as a theory check before the trunk: guess first, then watch it in the simulation.
    • In the rack view, ports have the colour of their VLAN; wrongly assigned ports stand out immediately.
    • The showcase “Data centre network” shows a whole design with core, distribution and access for presenting.

    Standards

    • IEEE 802.1Q – Bridges and Bridged Networks (current edition: IEEE 802.1Q-2022)
    • IEEE 802.1D – Media Access Control (MAC) Bridges (current edition: IEEE 802.1D-2004)
    • IEEE 802.1AX – Link Aggregation (current edition: IEEE 802.1AX-2020)
    • RFC 2131 – Dynamic Host Configuration Protocol

    Read on

    • VLANs and trunks One switch, several separate networks: access ports, trunks with 802.1Q tag, native VLAN and routing between VLANs.
    • Spanning tree (STP) Redundant cables without a broadcast storm: root bridge, port roles, blocked ports and what happens without STP.
    • Port channel and LACP Bundling several cables into one logical link: more bandwidth, resilience and no blocked port.
    • Layer 3 switch A switch that also routes: VLAN interfaces (SVIs) as gateways, routing between VLANs, DHCP relay, OSPF and VXLAN.
    • Access control lists (ACL) Named lists with permit and deny on a switch port or VLAN interface: stateless, first match applies, implicit deny at the end.
    • DHCP Handing out addresses automatically: discover, offer, request, ack, lease time, fixed assignments and DHCP relay across routers.
    • Network design: core, distribution, access Why large networks are built in layers, when a collapsed core is enough and what a data centre with leaf-spine looks like.
