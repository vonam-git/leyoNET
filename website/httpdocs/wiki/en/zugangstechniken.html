    The last mile

    Between the house and the provider lies the “last mile”. Depending on the location it is a coax cable of the cable network, a fibre, the old telephone line or radio. Each technology sets up the connection differently; the modem (or the home router) takes care of it.

    TechnologyLineSetup sequence
    DOCSIS 3.1 (cable)coaxsearch channel, ranging, DHCP and configuration file via TFTP, registration
    GPON (fibre)fibre, passively sharedreport serial number, receive ONU ID, ranging, configuration (OMCI)
    VDSL2, ADSL2+telephone linetraining (handshake), then PPPoE with login
    LTE (mobile)radioconnection to the cell, registration with SIM, bearer with IP address

    Shared media

    With cable and GPON many customers share the same medium. Therefore every modem must register and is assigned transmission times (ranging: the delay is measured so the signals do not overlap). DSL on the other hand is a separate line to the exchange, but its speed depends strongly on the length.

    In leyoNET

    The setup steps appear as frames of their own in the packet list. IP traffic only flows once the modem reports “online”. Attenuation, distance and bandwidth are not simulated. In the showcase three technologies run side by side: fibre in Zurich, cable in Bern, VDSL in Basel.

    Access lines

    The modem sets up the line to the provider according to its standard:

    • Cable (DOCSIS): channel scan, ranging, config via TFTP, registration
    • Fibre (GPON): serial number, ONU ID via PLOAM, config via OMCI
    • Mobile (LTE): RRC, attach with SIM, bearer with IP
    • ADSL/VDSL: training (G.hs), then PPPoE and PPP with user and password

    Only then do IP packets flow.

      First the box brings up the DOCSIS line, the computers get an address via DHCP, then the notebook loads a web page from the internet.

    • Data centre network

      Three data centres, three designs: Zurich three-tier (core, distribution, access), Bern with combined core and distribution, Basel as collapsed core. Everything is cabled redundantly: double links in a port channel (LACP) and every access switch connected to two switches, with spanning tree blocking the backup. All devices are mounted in racks, the ports carry the colour of their VLAN. The sites connect via fibre, cable modem and VDSL, linked with IPsec tunnels.

      A server in Zurich pings the NAS in Bern through the VPN tunnel, monitoring fetches the Basel web page by its DNS name, Bern queries the DNS server in Zurich, and Basel pings the Zurich monitoring.
