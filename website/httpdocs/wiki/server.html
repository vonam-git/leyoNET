    Wozu

    Ein Server stellt anderen Geräten Dienste bereit. In leyoNET kann jeder Server einen oder mehrere davon übernehmen; eingeschaltet werden sie unter Erweitert → Dienste:

    Dienstwas er tutSeite
    DHCPverteilt Adressen, Gateway und DNS-ServerDHCP
    DNSübersetzt Namen in Adressen (Zone mit A, AAAA, MX …)DNS
    Webliefert eigene HTML-Seiten und BilderHTTP
    MailPostfächer, Versand und AbholungE-Mail: SMTP, POP3 und IMAP

    Ausführungen

    Im Shop gibt es den Server als Tower und als Rack-Server. Rack-Server lassen sich in ein Rack einbauen und erscheinen in der Rack-Ansicht als Einschub. Technisch sind beide gleich.

    Feste Adressen

    Server haben in der Regel eine feste Adresse, damit Clients sie zuverlässig finden (DNS-Einträge, Gateway-Einstellungen). Der DHCP-Bereich darf diese Adresse nicht enthalten, sonst bekommt ein Client dieselbe Adresse: leyoNET markiert doppelte Adressen mit einem roten Ausrufezeichen.

    Server

    Ein Server bietet Dienste an: DHCP, DNS, Webserver und Browser und E-Mail. Im Shop gibt es ihn leer oder vorkonfiguriert. Der Webserver liefert eigene Seiten (index.html) und ein kleines Bild aus. Als Rack-Ausführung passt er in ein Racks.

    Private und öffentliche Adressen

    • Privat (10/8, 172.16/12, 192.168/16): nur im eigenen Netz, ins Internet über NAT/PAT
    • CGNAT (100.64/10): vom Provider vergeben, der nochmals übersetzt (Carrier-Grade NAT)
    • Öffentlich: weltweit eindeutig

    Mit A zeigt die Fläche alle Adressen farbig. Ein Bereich «Öffentliches Netz» markiert Netze mit öffentlichen Adressen, z.B. eine DMZ.
