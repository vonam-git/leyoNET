    Wozu

    PC und Notebook sind die Geräte, an denen Menschen arbeiten. Sie senden und empfangen, leiten aber nichts weiter. Das Notebook kann zusätzlich per WLAN ins Netz; ein PC braucht ein Kabel.

    Einstellungen

    EinstellungBedeutung
    IP-Adresse und Maskeeigene Adresse und Grösse des Netzes
    StandardgatewayRouter, an den alles geht, was nicht im eigenen Netz liegt
    DNS-Serverwer Namen wie www.schule.example in Adressen übersetzt
    DHCPstatt fester Werte alles automatisch vom DHCP-Server
    IPv6automatisch (SLAAC/DHCPv6) oder fest, je nach IP-Version des Projekts

    Der Desktop

    In der Simulation öffnet ein Doppelklick den Desktop des Geräts. Die Konsole allein öffnet die Taste T (auch aus dem Entwurf) oder «Konsole öffnen» im Fenster des Geräts:

    • Befehlszeile: ping, tracert, ipconfig /all, ipconfig /release und /renew, ifdown eth0 und ifup eth0 (Anschluss ab- und einschalten, auch ip link set eth0 down|up oder netsh interface set interface Ethernet disable|enable), arp -a, nslookup, netstat, ssh. Linux-Schreibweisen wie ip addr, ifconfig, dhclient -r gehen auch.
    • Webbrowser: zeigt jeden Schritt (DNS, TCP, HTTP) und die Seite.
    • E-Mail: Senden per SMTP, Abholen per POP3 oder IMAP.
    • Netzwerk: Adressen und Tabellen auf einen Blick.
    C:\> ipconfig /all
C:\> ping 192.168.1.1
C:\> tracert www.schule.example

    So geht es in leyoNET

    Derselbe Text wie in der Hilfe der App (Taste F1).

    PC

    Endgerät mit einem Ethernet-Port. Braucht IP-Adresse, Maske, Gateway und DNS-Server (IP-Adressen). Auf dem Desktop: Eingabeaufforderung (ping, tracert, ipconfig, nslookup), Browser und Mail.

    Notebook

    Endgerät mit Ethernet und WLAN. Bezieht seine Adresse fest oder per DHCP. Per WLAN verbunden, wechselt es in der Simulation beim Verschieben zum näheren Access Point (Roaming).

    Konsole der Endgeräte

    Jedes Endgerät (PC, Notebook, Server, Telefon) hat eine Eingabeaufforderung. Öffnen: Gerät wählen und T drücken, «Konsole öffnen» im Fenster des Geräts, oder in der Simulation Doppelklick auf das Gerät. Die Befehle brauchen die laufende Simulation; leyoNET wechselt bei Bedarf dorthin.

    • ipconfig (auch ipconfig /all, Linux: ip addr, ifconfig): Adresse, Maske, Gateway, DNS
    • ipconfig /release und ipconfig /renew (Linux: dhclient -r, dhclient): DHCP-Adresse abgeben bzw. neu holen
    • ifdown eth0 / ifup eth0 (auch ip link set eth0 down|up, Windows: netsh interface set interface Ethernet disable|enable): Anschluss ab- oder einschalten. Das ändert die Konfiguration wie das Abschalten im Fenster «Anschlüsse»
    • ping: -t läuft bis Strg+C (man sieht live, wann eine Verbindung abbricht), -n 10 bzw. -c 10 wählt die Anzahl, -i 1 die TTL (dann meldet der erste Router «TTL abgelaufen»)
    • tracert, nslookup, arp -a, arp -d, netstat, nmap (siehe Netzscanner), ssh, cls; help zeigt alle

    Router und Switches haben stattdessen eine Befehlszeile.
