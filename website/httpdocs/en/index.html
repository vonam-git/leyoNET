Made for the classroom

From the first year of vocational training to university. Teachers decide what is visible – and leyoNET does the marking.

Five profiles, one program

Beginners only see PCs, a switch, a router and DHCP. Each profile adds more – up to BGP. Teachers share their selection as a file.

  1. P1 Getting started PCs, switch, router, server, DHCP
  2. P2 Basics Wi-Fi, internet, DNS, web, static routes
  3. P3 Advanced VLANs, trunks, STP, NAT, firewall, loopbacks, command line
  4. P4 Professional OSPF, RIP, IPv6 with OSPFv3, layer 3 switch, ACLs, LACP, VPN, hex view, pcap
  5. P5 University everything, including BGP, VRF and VXLAN

Exercises that check themselves

Every exercise has learning goals such as “PC 1 reaches the web server”. One click on “Check” shows what is fulfilled and gives hints for the rest. Each exercise comes with a fillable worksheet as PDF (in German), plus whole series for the Swiss ICT modules 117, 129 and 145: all worksheets (ZIP). Teachers receive the model solutions by e-mail on request (address in the legal notice).

Create your own tasks in a form – or from a finished solution: leyoNET suggests the goals with points.

Exams without a pile of marking

Every seat gets its own code, an exam sheet to print and, if you like, its own variant. Work is saved every 20 seconds. Once submitted, nothing can be changed; the admin console shows live who is working and who submitted when.

Extra time per seat with one click. The evaluation computes points and the grade on the Swiss scale, with partial points, follow-on errors and room for manual corrections.

Series for the Swiss ICT modules 117, 129 and 145

Made for the Swiss vocational training in computer science (Informatiker/in EFZ): each module has a series of exercises that build on each other, with worksheet (PDF) and automatic checking.

M117 IT and network infrastructure for a small company IP addresses, switch and router, DHCP, DNS, web server, first troubleshooting with ping. M129 Putting LAN components into operation Subnetting, static routing, protocol analysis with a packet list like in Wireshark. M145 Operating and extending a network VLANs, trunks, inter-VLAN routing, DHCP relay, spanning tree and network design.

The whole class in one network

Each group builds its own site and connects it to the teacher’s class infrastructure. leyoNET simulates the whole network: whoever addresses, routes and configures NAT correctly is online – and the head office fetches the site’s web page.

  • Dashboard for the projector: map and tiles show live who is connected, online or done. Only what really works in the simulation turns green.
  • Messages between sites: they are only sent if your own site reaches the head office.
  • Seat and group instead of names: “Team Red” on seat 1 is enough.
  • Own access keys for schools and teachers, without accounts and without personal data. Exercises and whole modules can be shown or hidden per class.

What really happens in the network

Every frame consists of real bytes, encoded according to the standards. The packet view unpacks it layer by layer, the hex view highlights every field, and after export Wireshark opens the same capture.

  • Display filters like in Wireshark: icmp and ip.dst == 192.168.2.20
  • Command line for routers and switches in the style of FRRouting, with Tab and ?
  • Slow motion and single step: packets travel across the cables as dots
  • Damage cables, shut down ports, troubleshoot

No accounts. No cookies. No tracking.

leyoNET only stores network configurations, never names. The file loads nothing from the internet, not even a font. The single file and the desktop app transmit nothing at all; the web version only stores technical data without names and deletes it automatically. What exactly is stored is described in the privacy policy (in German).

The source code is open (AGPL-3.0). Before release, every version is checked for trackers, external resources, security headers and licences.

From the classroom

Mark teaches networking. For years he and his classes pulled cables, sent pings and conjured up broadcast storms – mostly on purpose. At some point it was clear: a more modern tool was needed, one that simply runs in the browser and can still be installed locally.

Together with his brother Mika he built the foundation; since then, idea after idea from the classroom has been added. It is programmed with the help of artificial intelligence – the ideas, the experience and the responsibility lie with Mark and Mika.

And the name? “leyo” are the initials of Mark’s children. The logo shows an “l” and a “y” made of network nodes: “ly” for “love you”. Every good network needs strong connections.

Get started

The same program everywhere. Version 1.7.1.

  • In the browser

    Start right away, save your work under a code, classes and exams via the server.

    Open app.leyonet.ch

  • Single file

    One HTML file that runs everywhere: a double-click is enough. Ideal for USB sticks and exam computers without internet.

    leyonet.html approx. 2 MB

  • Windows

    Windows 10 and 11. Installer or MSI for deployment in the school network.

    Setup (.exe) approx. 4 MB MSI approx. 5 MB

  • macOS

    For Apple Silicon and Intel (macOS 10.15 or later).

    macOS (.dmg) approx. 5 MB

  • Linux

    AppImage runs without installation; packages for Debian/Ubuntu and Fedora.

    AppImage approx. 80 MB .deb approx. 2 MB .rpm approx. 2 MB

The files come directly from GitHub. Checksums (SHA-256) for comparison: SHA256SUMS.txt. All versions and changes: GitHub Releases. The installers are not signed yet. On first start Windows shows “Windows protected your PC”: More info → Run anyway. On the Mac, start it the first time with right-click → Open or under System Settings → Privacy & Security → Open Anyway. If macOS reports the app as “damaged”, run xattr -cr /Applications/leyoNET.app in the Terminal.
