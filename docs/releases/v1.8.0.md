## leyoNET 1.8.0: Prüfungen im Cockpit erstellen, Fehlersuche je Platz, SEB ganz einstellbar

Version 1.8.0 bringt das Erstellen von Prüfungen direkt in die Admin-Konsole, eine Fehlersuche-Übung für den Klassen-Verbund mit anderen Fehlern an jedem Platz und alle wichtigen Einstellungen des Safe Exam Browsers. Betreiber müssen nichts umstellen; nach dem Update die Node.js-App neu starten.

### Downloads

| System | Datei |
|---|---|
| Windows | `leyoNET-Windows-Setup.exe` (oder `leyoNET-Windows.msi`) |
| macOS (Intel und Apple Silicon) | `leyoNET-macOS.dmg` |
| Linux | `leyoNET-Linux.AppImage`, `leyoNET-Linux.deb` oder `leyoNET-Linux.rpm` |
| Ohne Installation | `leyonet.html` (eine Datei, läuft offline im Browser) |
| Arbeitsblätter | `leyoNET-Arbeitsblaetter.zip` (alle PDFs für Lernende) |

Prüfsummen: `SHA256SUMS.txt`. Im Browser: [app.leyonet.ch](https://app.leyonet.ch). Die Installer sind nicht signiert; siehe [docs/desktop.md](https://github.com/vonam-git/leyoNET/blob/main/docs/desktop.md).

### 📝 Prüfungen

- **Hier erstellen:** Admin-Konsole → Prüfungen → Neue Prüfung → «Hier erstellen». Vorlage **Fehlersuche**: ein fertiges Firmennetz mit drei Standorten, an jedem Platz andere Fehler (Anzahl 1–8, Fehlerarten wählbar, auf Wunsch verraten die Ziele nicht, wo der Fehler steckt). Vorlage **Aufbauen (M117)**: je Platz eine eigene Variante. Prüfungsdatei und Schlüssel entstehen im Browser und gehen direkt an den Server, ohne Dateien herumzureichen.
- **Nur für Admins:** In der Webversion erstellen nur angemeldete Admins Prüfungen. In der Einzeldatei und der Desktop-App bleibt alles wie bisher.
- **Code zum Beenden mit begrenzten Versuchen:** Bei Server-Prüfungen prüft der Server den Code. Erlaubte Versuche (Vorgabe 5) und Sperre (Vorgabe 10 Minuten, 0 = bis zur Freigabe) sind je Prüfung einstellbar. Das Cockpit zeigt Fehlversuche und gesperrte Plätze und gibt sie mit «Freigeben» frei.
- **Safe Exam Browser ganz einstellbar:** Admin- und Beenden-Passwort auch als fertiger SHA-256-Hash (z.B. das Passwort der Schul-IT). Dazu Beenden erlaubt, ein Knopf «Safe Exam Browser beenden» nach der Abgabe (`quitURL`), Tastenkürzel sperren, Neu laden, Taskleiste, Uhr, Zoom, Rechtschreibprüfung, Zwischenablage, virtuelle Maschine, Bildschirm teilen, WLAN, Mikrofon, Kamera, Anzahl Bildschirme und weitere erlaubte Adressen. Der Browser merkt sich die Einstellungen, nie die Passwörter. Eine Grenze für Passwort-Versuche gibt es im SEB selbst nicht; dafür begrenzt leyoNET die Versuche beim Code zum Beenden.
- **Jeder Platz bekommt nur seine Variante:** Bei Prüfungen über den Server liefert der Server jedem Platz nur seine eigene Variante und nicht mehr den Prüfwert des Codes zum Beenden. So lässt sich weder die Lösung einer Fehlersuche durch Vergleich ablesen noch der Code offline erraten.
- **Neue Fehlerarten** für alle Fehlersuchen: Portweiterleitung zeigt auf den falschen Rechner, Standardroute fehlt. Dazu die Prüfbausteine «Portweiterleitung» und «Standardroute» im Aufgabeneditor.

### 🌐 Klassen-Verbund

- **Fehlersuche im Verbund-Standort** (★★★★): ein fertiger Standort mit Webserver, DHCP und DNS, in den an jedem Platz 5 andere Fehler eingebaut sind. Abschreiben hilft nicht; beim erneuten Öffnen bleiben die Fehler gleich, eine andere Klasse bekommt eine andere Verteilung.
- **Dashboard:** Jede Kachel zeigt «Fehler behoben n/5» als fünf Felder. Wer alle hat und online ist, wird grün.
