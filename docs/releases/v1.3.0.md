## leyoNET 1.3: Prüfen mit dem Safe Exam Browser

Version 1.3 bindet Prüfungen der Webversion an den Safe Exam Browser und macht Racks übersichtlich verkabelt.

### Downloads

| System | Datei |
|---|---|
| Windows | `leyoNET-Windows-Setup.exe` (oder `leyoNET-Windows.msi`) |
| macOS (Intel und Apple Silicon) | `leyoNET-macOS.dmg` |
| Linux | `leyoNET-Linux.AppImage`, `leyoNET-Linux.deb` oder `leyoNET-Linux.rpm` |
| Ohne Installation | `leyonet.html` (eine Datei, läuft offline im Browser) |
| Arbeitsblätter | `leyoNET-Arbeitsblaetter.zip` (alle PDFs für Lernende) |

Prüfsummen: `SHA256SUMS.txt`. Im Browser: [app.leyonet.ch](https://app.leyonet.ch). Die Installer sind nicht signiert; Windows (SmartScreen) und macOS fragen beim ersten Start nach, siehe [docs/desktop.md](https://github.com/vonam-git/leyoNET/blob/main/docs/desktop.md).

### Prüfungen

- **Nur im Safe Exam Browser:** Beim Anlegen einer Prüfung ankreuzen. Das Cockpit erzeugt eine SEB-Datei mit **Start-, Admin- und Beenden-Passwort** (zufällig vorgeschlagen, änderbar, nirgends gespeichert) und einem **zufälligen Prüfungsschlüssel**, der gilt, solange die Prüfung läuft. Die Datei startet leyoNET direkt mit «Prüfung beitreten» und erlaubt nur den eigenen Server. Ohne SEB nimmt der Server weder Beitritt noch Speichern an.
- **Session ansehen:** Das Aufgabenfenster springt bei jedem neuen Stand nicht mehr auf; stattdessen kurz «Neuer Stand erhalten».

### Racks

- **Rack-Ansicht:** Hostname als Etikett, Patchkabel zwischen den Geräten im Rack über einen Kabelkanal, Hervorheben beim Überfahren eines Ports, Kabel nach aussen als Liste.
- **Zeichenfläche:** eingebaute Geräte mit Etikett und Typ; Kabel im Rack als Patchkabel am Rand mit Port und LED statt quer über die Geräte.

### Netzwerk

- Router und Layer-3-Switch lehnen **zwei Interfaces im selben Netz** ab, wie echte Geräte (in verschiedenen VRFs erlaubt).
- Neue Server heissen wieder «Server 1» statt «defaultName.server 1»; alte Dateien werden beim Öffnen repariert.

### Unterricht

- Die Musterlösungen der Arbeitsblätter erhalten Lehrpersonen auf Anfrage (Adresse im Impressum auf leyonet.ch).

### Oberfläche

- Die Seite scrollt nicht mehr: nach Rauszoomen bleibt unten kein leerer Streifen.

### Für Betreiber der Webversion

Nach dem Update in Plesk die Node.js-App neu starten (geänderter Server). Neue Umgebungsvariablen braucht es nicht. Projektdateien aus 1.0 bis 1.2 lassen sich unverändert öffnen.
