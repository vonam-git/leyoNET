## leyoNET 1.6.1: sicherer Server, Exporte und Verbesserungen für den Unterricht

Version 1.6.1 härtet den Server der Webversion nach einer ausführlichen Sicherheitsprüfung, bringt Exporte für die Netzdokumentation und setzt mehrere Rückmeldungen aus dem Unterricht um.

### Downloads

| System | Datei |
|---|---|
| Windows | `leyoNET-Windows-Setup.exe` (oder `leyoNET-Windows.msi`) |
| macOS (Intel und Apple Silicon) | `leyoNET-macOS.dmg` |
| Linux | `leyoNET-Linux.AppImage`, `leyoNET-Linux.deb` oder `leyoNET-Linux.rpm` |
| Ohne Installation | `leyonet.html` (eine Datei, läuft offline im Browser) |
| Arbeitsblätter | `leyoNET-Arbeitsblaetter.zip` (alle PDFs für Lernende) |

Prüfsummen: `SHA256SUMS.txt`. Im Browser: [app.leyonet.ch](https://app.leyonet.ch). Die Installer sind nicht signiert; siehe [docs/desktop.md](https://github.com/vonam-git/leyoNET/blob/main/docs/desktop.md).

### 🔒 Sicherheit der Webversion

- **Ratenbegrenzung** auch hinter einem Unix-Socket (Plesk/Passenger) und je IPv6-/64-Netz: Wer Codes oder Passwörter rät, bremst nur sich selbst, nicht die ganze Schule.
- **Zugangsschlüssel** von Schulen und Lehrpersonen werden nicht mehr gesperrt, wenn jemand anderes das Admin-Passwort falsch eingibt.
- **Prüfungen:** Ein Prüfungsplatz bleibt beim ersten Gerät, bis die Lehrperson ihn im Cockpit mit «Freigeben» freigibt (bisher war er nach einer Minute ohne Lebenszeichen wieder frei). Nach der Abgabe nimmt der Server keine Arbeit mehr an, Safe Exam Browser wird auch beim Lesen verlangt.
- Platz-Codes und Prüfungen liegen im Arbeitsspeicher, Passwörter werden asynchron gehasht (scrypt), der Stand wird erst nach dem vollständigen Lesen einer Anfrage geladen.
- **Lieferkette:** GitHub Actions auf feste Commits gepinnt, Schreibrechte je Auftrag, Dependabot für Sicherheitsupdates, Lizenzprüfung mit fester Version.

### 📄 Exporte

- **Datei → Netzdokumentation exportieren (CSV):** Adressplan (je Anschluss Gerät, IP, Maske, Netz, Gateway, DNS, MAC, VLAN) und Verbindungen für Excel oder LibreOffice.
- **Konfiguration als Text:** alle Router, Switches und Firewalls in einer Datei, wie «show running-config».

### 🏫 Für den Unterricht

- Einheitlich **«Transitnetz»** (RFC 2328) für das Netz zwischen zwei Routern, mit Erklärung im Wiki.
- Die MAC-Tabelle heisst auch **SAT** (Source Address Table).
- Der bearbeitete Router-Anschluss ist auf der Zeichenfläche hervorgehoben.
- Eine Aufgabe öffnet nach Rückfrage in einem leeren Projekt.
- **Klassen-Verbund:** Klassencode beim Eröffnen wählbar und verlängerbar (höchstens 180 Tage); Verbund-Übungen zeigen den Kasten «Dein Platz im Klassen-Verbund» mit Platz, Transitnetz, WAN-Adresse und Ziel.
- Schaltfläche **«Admin»** in der Werkzeugleiste (Alt+A).

### Für Betreiber der Webversion

- **Node.js 22 oder neuer** ist nötig (in Plesk unter Node.js einstellen).
- Empfohlen: **`DATA_DIR`** auf einen Ordner ausserhalb von `httpdocs` setzen. Der Server weist beim Start darauf hin, solange der Datenordner im Programmordner liegt. Siehe [docs/plesk.md](https://github.com/vonam-git/leyoNET/blob/main/docs/plesk.md).
- Nur **einen** Node-Prozess betreiben: Anmeldungen, Lebenszeichen und Zähler liegen im Arbeitsspeicher.
- Nach dem Update: *Git → Pull Updates*, *Jetzt bereitstellen*, *Node.js → App neu starten*.
