## What it is about

In module 129 learners put LAN components into operation: they divide a network into subnets, connect routers statically, bring the company network to the internet with NAT and analyse what really happens on the wire. leyoNET encodes every frame in real bytes, the packet list shows them layer by layer like Wireshark.

The series has four parts: subnetting, static routing, dynamic routing (RIP and OSPF) and protocol analysis. For routing the worksheets contain only the theory and example commands with other addresses: learners work out the commands for their own network themselves and write them on the sheet. Every router exercise ends with saving via `copy running-config startup-config`.

## Theory in this order

1. [[zahlensysteme]], [[subnetting]] and [[adressbereiche]]: masks, VLSM, private addresses.
2. [[routing-grundlagen]] and [[statisches-routing]]: routing table, longest prefix.
3. [[nat]] and [[ssh]]: to the internet and secure management.
4. [[rip]] and [[ospf]]: routers exchange their networks themselves.
5. [[rahmen-und-pakete]]: how Ethernet, IPv4, TCP and UDP are structured.
6. [[icmp]], [[dhcp]], [[arp]], [[dns]] and [[http]]: the protocols of the analysis.

## Teaching tips

- Compute the subnetting tasks on paper first, then check them in leyoNET: the exercise reports which subnet is wrong.
- For protocol analysis run the simulation in slow motion or single step and switch off “Each packet once” to see the path over every switch.
- Under every layer, “Structure per standard” shows the header with the values of the frame, exactly as in the wiki.
