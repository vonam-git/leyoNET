## Why documentation belongs to it

A network nobody understands cannot be operated. In leyoNET, documentation is part of the network: areas, colours and descriptions are stored in the same file as the configuration and can be assessed in exercises and exams.

## The tools

- **Areas:** coloured surfaces with title, network address (leyoNET computes mask, host range and broadcast), VLAN and note. An area with a VLAN colours the switch ports of that VLAN.
- **Notes:** text boxes with title, paragraphs, lists and **bold**, e.g. for a VLAN plan.
- **Racks:** 19-inch cabinets on the canvas. Drag devices into them and they are stacked as rack units. View → Rack view (key R) shows all racks with front panels, link LEDs, colour tags and patch cables.
- **Ports:** every interface has a colour and a description (“Uplink core”), like the labels in a real rack.
- **Floors:** devices and areas lie on floors; Wi-Fi signals get weaker across floors.
- **Snapshots:** named intermediate states, automatically before every start of the simulation.
- **Costs:** reference prices for all devices and cables, total in CHF; exercises can require a budget.

## A good example

The [showcase](https://app.leyonet.ch/?schaufenster) shows a fully documented data centre network: an area with its network per site, racks by layer (core, distribution, access), ports in the VLAN colours, turquoise for trunks and a VLAN plan as a note. This is exactly how learners should hand in their own networks.
