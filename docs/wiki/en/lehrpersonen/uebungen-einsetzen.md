## How an exercise works

Tools → **Exercise catalog** opens all exercises, by stars (★ to ★★★★★), topics and module series (M117, M129, M145). An exercise loads a starting network and shows the **learning goals** on the left, e.g. “PC 1 reaches the web server”. **Check** runs the simulation in the background and ticks off what is fulfilled, with a hint for every open goal. Solved exercises stay marked in the catalog.

Every exercise switches on the features it needs. Each has a **model solution in the code** that is checked automatically at every release. So there cannot be an exercise that is impossible to solve in leyoNET.

## Worksheets

Every exercise has a **fillable worksheet** (PDF, in German) with the questions that cannot be checked automatically: computing the network ID, observations in the packet list, reasoning. The worksheets are in the project under [docs/arbeitsblaetter](https://github.com/vonam-git/leyoNET/tree/main/docs/arbeitsblaetter) and in every release as a ZIP. Model solutions are available to teachers on request (address in the [legal notice](../../impressum.html)).

## Evaluating submissions

Learners save their project (Ctrl+S) and hand in the file, e.g. via Teams or Moodle. **Evaluate submissions …** (on the left under “Task”) loads all files of a class at once, checks each against the learning goals and exports the result as CSV for Excel. The web version needs no files: you see the class’s sessions directly ([[webversion]]).
