## What leyoNET is

leyoNET is a network simulator for teaching. Learners build networks from devices they drag from a shop onto the canvas, configure them like real devices and then switch to the **simulation**. Real protocols run there: every frame is encoded according to the standards and can be examined layer by layer, down to the individual bytes.

There are no accounts and no tracking. leyoNET runs in three ways, the same everywhere:

| Variant | For | Saving |
|---|---|---|
| In the browser: [app.leyonet.ch](https://app.leyonet.ch) | start right away, classes, exams, watching | session code on the server (network configuration only) |
| One file: `leyonet.html` | offline, USB stick, exam computers without internet | in the browser of the device, exportable as a file |
| Installed (Windows, macOS, Linux) | own program window | like the file |

## The plan for the first 30 minutes

1. **5 minutes – watch:** open the [showcase](https://app.leyonet.ch/?schaufenster). Three data centres run live; clicking a device shows its settings on the right, the packet list at the bottom (arrow at the lower edge) shows the packets.
2. **10 minutes – build yourself:** [[erstes-netz]]: two PCs, a switch, a ping.
3. **5 minutes – understand packets:** [[simulation-verstehen]]: packet list, OSI view, single step.
4. **5 minutes – choose a profile:** [[profile]]: what should your learners see?
5. **5 minutes – first exercise:** Tools → Exercise catalog, start a one-star exercise and press “Check” ([[uebungen-einsetzen]]).

> **Tip for the first lesson:** present a demo (File → Demo networks → “Present”), then let the class solve the same exercise from the catalog themselves. The exercise checks itself, you walk around and help.
