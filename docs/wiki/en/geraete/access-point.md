## What for

An access point connects wireless devices to the wired network. It works like a switch on layer 2: for the clients on Wi-Fi and the devices on the cable it is the same network. It only needs an IP address for management.

## Settings

| Setting | Meaning |
|---|---|
| SSID | name of the Wi-Fi network that clients see |
| Password | WPA2 key; without a password the network is open |
| Band and channel | 2.4 or 5 GHz; neighbouring access points on different channels |
| Mesh | access points connect by radio instead of cable |

## Several access points

If several access points have the same SSID and password, clients switch to the stronger one when moved (**roaming**). In a **mesh** one cable to the first access point is enough; the others connect by radio, even across floors. [[wlan]] explains how joining works.
